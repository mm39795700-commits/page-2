# منصة امتحانات الدراسات الاجتماعية — الصف الثاني الإعدادي 🇪🇬

منصة تعليمية إلكترونية متطورة وشاملة مخصصة لطلاب الصف الثاني الإعدادي في جمهورية مصر العربية لمادة **الدراسات الاجتماعية**.

---

## 🌟 مميزات المنصة

1. **دعم كامل للغة العربية واتجاه اليمين لليسار (RTL)** مع خطوط تعليمية راقية ومريحة للعين (`Cairo` و `Alexandria`).
2. **تصميم متجاوب 100% (Responsive)** يعمل بكفاءة وسلاسة فائقة على:
   - الهواتف الذكية (Mobile-First).
   - الأجهزة اللوحية (Tablets).
   - أجهزة الحاسوب والشاشات الكبيرة (Desktop).
3. **نظام متعدد الدروس (Multi-Lesson Architecture)**:
   - **الدرس الأول**: متاح الآن بأسئلته الـ 10 الدقيقة ونظام تصحيح فوري ولوحة شرف مستقلة.
   - **الدرس الثاني والدرس الثالث**: بطاقات جاهزة مع شارة "الامتحان غير متاح حالياً" مع بنية برمجية معزولة مهيأة لتفعيل الأسئلة فور توفرها.
   - سهولة تامة في إضافة الدرس الرابع والخامس والسادس مستقبلاً دون المساس بكود الواجهة.
4. **التحقق من اسم الطالب**: منع دخول الامتحان باسم فارغ وحفظ اسم الطالب مع نتيجته.
5. **لوحة شرف مستقلة لكل درس (Isolated Leaderboard)**:
   - نتائج وأوائل كل درس منفصلة تماماً عن بقية الدروس.
   - ترتيب فوري وتلقائي حسب الدرجة الأعلى ثم النسبة.
   - منصة تتويج للمراكز الثلاثة الأولى (🥇 🥈 🥉).
6. **مراجعة تفصيلية للإجابات**:
   - توضيح الإجابة المختارة والإجابة النموذجية مع تمييز بصري واضح وإشارات ملائمة لسهولة الوصول.
7. **إمكانية إعادة الامتحان**: تصفير الإجابات وخوض المحاولة من جديد.
8. **احتفال تفاعلي (Confetti)** للمتفوقين الحاصلين على 80% فأكثر.

## 🚀 كيفية التشغيل والمعاينة

### الطريقة 1: الفتح المباشر في المتصفح
يمكنك فتح ملف `index.html` مباشرة بالنقر المزدوج عليه في أي متصفح (Google Chrome, Microsoft Edge, Firefox, Safari) بدون الحاجة إلى أي برامج إضافية.

### الطريقة 2: التشغيل عبر الخادم المحلي (Node.js)
افتح الطرفية (Terminal) داخل مجلد المشروع ونفذ:
```bash
node server.js
```
ثم توجه في المتصفح إلى: `http://localhost:3000`

## 🔧 كيفية إضافة أسئلة للدرس الثاني أو الثالث مستقبلاً

في ملف `js/data.js`، توجه إلى الكائن الخاص بـ `lesson-2` وقم بتعديل الحقول التالية:
1. غيّر `isAvailable: true`
2. غيّر `statusText: "متاح الآن"`
3. ضع الأسئلة داخل مصفوفة `questions: [...]` بنفس هيكلية أسئلة الدرس الأول:
```javascript
{
  id: 1,
  text: "نص السؤال هنا...",
  options: [
    { key: "أ", text: "الخيار الأول" },
    { key: "ب", text: "الخيار الثاني" },
    { key: "ج", text: "الخيار الثالث" },
    { key: "د", text: "الخيار الرابع" }
  ],
  correctAnswer: "أ"
}
```
ستعمل المنصة فوراً وتنشئ لوحة شرف جديدة خاصة بالدرس الثاني دون أي تعديل إضافي في كود التطبيق!
